# Dian Abidin — Personal Portfolio

## Cara menjalankan
1. Ekstrak folder ZIP.
2. Buka `index.html` di browser untuk melihat website.
3. Untuk hosting gratis, unggah folder ini ke Netlify Drop atau gunakan GitHub Pages.

## Personalisasi sebelum dipublikasikan
- Edit teks About Me, Experience, software, skills, dan deskripsi proyek di `index.html`.
- Pada formulir kontak, ganti `emailkamu@example.com` dengan alamat email tujuan.
- Gambar referensi disimpan di folder `assets/`. Kamu bisa menggantinya dengan foto/karya asli resolusi tinggi.

Website memiliki navigasi responsif, menu mobile, animasi loading, penanda bagian aktif, modal detail proyek, tombol kembali ke atas, efek kursor desktop, dan formulir yang menyusun pesan email.
